# Videos Folder

Place your project video files here.

## Required Videos

- `eduvibe.mp4` - Video for Eduvibe project
- `kilymo.mp4` - Video for Kilymo project
- `project3.mp4` - Video for Project Three
- `project4.mp4` - Video for Project Four

## Video Specifications

- Format: MP4 (H.264 codec recommended for best compatibility)
- Recommended resolution: 1920x1080px (Full HD)
- Recommended bitrate: 5-10 Mbps
- Keep file sizes optimized (consider compression)

## Video Hosting Alternatives

For better performance, consider hosting videos on:
- **Vimeo** - Professional hosting with privacy controls
- **YouTube** - Free hosting (can be unlisted)
- **Cloudflare Stream** - Optimized delivery
- **AWS S3 + CloudFront** - Self-hosted solution

If using hosted videos, update the `videoUrl` in `src/components/Projects/Projects.jsx` to use embed URLs instead of local files.
